🧠 How I Approach Problems

When I encounter a problem, I try to ask:

01 — Is the problem real?

Not every interesting idea is a meaningful problem.

02 — Who experiences it?

A solution should have a clearly identifiable user.

03 — Why does the problem exist?

Understanding the root cause is more important than immediately writing code.

04 — Can technology actually help?

Not every problem needs AI.

05 — What data is required?

Healthcare technology depends heavily on data quality and context.

06 — How do we validate it?

A healthcare system cannot be judged only because the interface looks good.

07 — What are the limitations?

Knowing when a system can fail is as important as knowing when it works.

08 — Where should human expertise remain?

Technology should augment responsible professional decision-making rather than blindly replace it.
